# Scaffold Design

## Introduction

This guide documents the algorithmic design of scaffolds originating from an XChem fragment screen and should be followed alongside Template_Workflow.ipynb.

This template will guide you through the process of setting up a local HIPPO database, running algorithmic merges of a subset (or all) of fragment inspirations from a given target, scoring these scaffolds with GNINA and exporting the results for visualisation in pyMOL or fragalysis.

To get started, make a copy of Template_Workflow.ipynb in the same root directory and name it something sensible <target_name>_cycle_01.ipynb. From here follow the template cell by cell to generate new designs for triaging.
